## Model / decisions
- **Leitner is primary, ease is a modifier.** Boxes 1–5 with fixed base
  intervals `[_,1,3,7,16,35]` days. The SM-2 `ease` (default 2.5, clamped
  [1.3, 3.0]) multiplies the good/easy interval (`ease/2.5`) so the schedule
  personalises without leaving the Leitner frame.
- **Grade ladder:**
  - `again` → box 1, interval 0 (re-show this session), reps 0, ease −0.20
  - `hard`  → stay in box, interval = max(1, round(box×0.5)), ease −0.15
  - `good`  → +1 box, interval = round(boxInterval × ease/2.5), ease ±0
  - `easy`  → +2 boxes (the reward), interval scaled by ease, ease +0.15
  - chose **easy = +2 boxes** rather than relying on ease alone, because at low
    boxes a ±0.15 ease change rounds to the same interval as `good` — the box
    jump is what makes "easy" meaningfully longer.
- **Entry into review is explicit.** A default `srs` (all zeros, `nextReviewAt`
  0) is **not** due. Words enter the queue via `seedReview` (due after the
  box-1 interval) or via the first `schedule` grade. This keeps brand-new,
  read-only words out of the review queue until something opts them in (2.2).
- **Two API styles, matching the codebase:** pure functions (`schedule`,
  `seedReview`, `isDue`, `dueWords`, `countDue`) return new values; the
  `gradeWord(bank, …)` helper mutates a bank record like `applyExposures`.
