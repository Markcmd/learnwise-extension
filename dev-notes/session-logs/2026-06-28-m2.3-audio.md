# 2026-06-28 — M2.3: pronunciation audio (Web Speech API)

## Goal
Let users hear how a word is pronounced — on review cards (the main learning
surface) and on inline glossed words.

## What shipped
- **`JSs/dom/speech.js`** — wrapper over `window.speechSynthesis`:
  `speak(text,{lang,rate})`, `cancelSpeech`, `speechSupported`,
  `ensureVoices`, and the pure `pickEnglishVoice`.
- **Review** (`review.html`/`.css`/`.js`): speaker button by the word,
  auto-play on reveal (setting `SPEECH_AUTOPLAY`, default on), **P** to replay.
- **Glossed words** (`dom/renderer.js`): **Alt/Option+click** pronounces;
  plain click still marks known. Ruby `title` hint added.
- **Constants:** `SPEECH = {LANG:"en-US", RATE:0.95}`, `SPEECH_AUTOPLAY`.
- **Tests:** `tests/speech.test.js`. Manifest → 1.0.5.

## Decisions
- **No TTS audio files / no network.** `speechSynthesis` is built into the
  browser, offline, free — fits the "local-first, no server" principle. The
  trade-off is voice quality varies by OS, but it's zero-cost and instant.
- **Voice picking is the only pure bit** (`pickEnglishVoice`) so it's unit
  tested; everything touching `speechSynthesis` is isolated in `dom/speech.js`
  and verified manually (same pattern as other `dom/` glue).
- **Voices load async.** `ensureVoices` resolves on `voiceschanged` (or a 1s
  timeout). `speak` also reads `getVoices()` live, so even a cold first call
  works (falls back to the engine default if the list isn't ready yet).
- **Glossed-word gesture = Alt+click**, chosen to *not* collide with the
  existing click-to-know. Discoverability via the `title` tooltip. Considered
  per-word speaker icons but rejected as too visually noisy inline.
- **Rate 0.95** — very slightly slowed, better for learners without sounding
  robotic.

## Verification
- `pickEnglishVoice` Node-verified: **8 assertions pass**. Import paths +
  exports checked. esbuild still can't run in-sandbox (host-specific binary).
- **On your machine:** `npm run build` (folds `speech.js` into `dist/review.js`
  and `dist/contentScript.js`) then `npm test`. Manually: open Review and
  reveal a card (should hear it); Alt+click a glossed word on any page.
